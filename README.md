# LB Social Studio

Site institucional da LB Social Studio.

## Stack

- React
- Vite
- Lucide React
- Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Estrutura

```text
public/images/   imagens do site
src/App.jsx      componentes e conteúdo
src/styles.css   estilos e design tokens
src/main.jsx     entrada da aplicação
```

A branch `main` deve ser conectada à Vercel para deploy automático.
